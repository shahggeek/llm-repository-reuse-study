# Independent Blinded Reuse Review

## Purpose

This review tests whether a second reviewer can apply the R0–R3 reuse rubric
without knowing which implementation was generated by the model and which came
from SR-Eval. It is a reliability check, not another model run.

## Reviewer procedure

1. Open `pilot-a-reuse-blinded-review.xlsx` and read the `Instructions` sheet.
2. Review all 20 implementation rows in the `Review` sheet. Each of the ten
   cases has variants A and B; do not try to infer their origin.
3. Use the `Code` and `Context` sheets for the implementation, cumulative task
   instructions, supplied model context, repository path, and target line.
4. For each A/B implementation, enter reuse class, context class, candidate
   symbol, evidence, maintenance consequence, and confidence.
5. Export the completed `Review` sheet as CSV without renaming its columns.
6. Give only the completed workbook or CSV to the study owner. Do not inspect
   the concealed key or the primary classifications before submitting.

## Blinding

Case order and A/B assignment are fixed by the concealed mapping in
`results/pilot/pilot-a-reuse-blind-key.json`. The review workbook contains
neither that mapping nor the primary analyst's classifications. The agreement
script selects the generated implementation only after the second reviewer has
submitted classifications for both variants.

## Agreement calculation

Run:

```bash
python3 scripts/calculate_reuse_agreement.py \
  path/to/completed-review.csv \
  --output results/pilot/pilot-a-reuse-review-agreement.json
```

The script requires all 20 A/B rows, validates R0–R3 and C0–C3 values, and
reports:

- exact agreement for R0–R3;
- linearly weighted Cohen's kappa for R0–R3;
- agreement on the binary R2/R3 missed-reuse decision;
- exact agreement and linearly weighted kappa for C0–C3; and
- case-level disagreements for adjudication.

Kappa is descriptive because the calibration sample has only ten generated
checkpoints. Report the statistic with the sample size and raw agreement; do
not use a threshold alone to declare the rubric reliable.
